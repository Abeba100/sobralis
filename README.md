# Собрались — во что поиграть?

Сервис подбирает игры для компании по количеству участников, времени, настроению и доступному реквизиту.

**[Открыть сайт на GitHub Pages](https://abeba100.github.io/sobralis/)**

## Возможности

- 24 игры с пошаговыми правилами, включая «Крокодила», «Шляпу» с персонажами и предметами и «Кто я?».
- Поиск по названию без учёта регистра.
- Фильтры для компаний от 2 до 20 человек.
- Случайный выбор подходящей игры.
- Избранное в localStorage текущего браузера.
- Таймер раунда с паузой и сбросом.
- Ссылка на подборку с сохранёнными параметрами поиска и фильтров.
- Адаптивный интерфейс на русском языке.

## Запуск

Нужен Node.js 20 или новее. Установка зависимостей не требуется.

```sh
git clone https://github.com/Abeba100/sobralis.git
cd sobralis
npm start
```

Откройте http://127.0.0.1:4173 в браузере. Приложение использует JavaScript-модули, поэтому запускайте его через сервер, а не открытием HTML-файла.

## Проверки

```sh
npm test
```

Проверяются подбор по фильтрам, поиск, избранное, доступность игр для разного количества участников и полнота игровых карточек.

## Структура

```text
dist/
  index.html  — страница и окно правил
  style.css   — оформление и адаптивные стили
  games.js    — каталог игр и функция подбора
  app.js      — поиск, фильтры, избранное и таймер
server.mjs    — локальный HTTP-сервер
checks.mjs    — проверки через node:test
```

## Размещение

Содержимое `dist/` можно разместить на любом статическом хостинге. Серверная часть и ключи API не нужны. Шрифт Golos Text загружается с Google Fonts; при отсутствии сети используется системный шрифт.

Правила представлены в коротких домашних вариантах. Приложение помогает выбрать игру и прочитать правила; участники играют вместе вживую.
